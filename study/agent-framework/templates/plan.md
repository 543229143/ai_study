## 维护约定

1. 同一时间「现在做」只有一条。
2. 新增条目必须同时写「判定证据」，否则不写。
3. 完成 = 证据跑通 + checkpoint 落盘 + 人签字，三者缺一不算。
4. 条目被退回时保持 `- [ ]`，不许改成"部分完成"糊过去。
5. 文档是母本，不动；本文件是当前视图，随进度移动。
